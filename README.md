# Listening for Black Holes

An interactive gravitational-wave exploration project focused on
binary black hole (BBH) signal detection using machine learning.

## Project components

- Dataset generation for gravitational-wave signals and noise
- Deep-learning model training
- Matched-filter baseline evaluation
- Interactive HTML visualization

## Notebooks

- `BBH_GW_Dataset_Generation_v2.ipynb` — dataset generation
- `BBH_GW_Training_v2 (1).ipynb` — model training
- `BBH_GW_MatchedFilter_Baseline_v5.ipynb` — baseline evaluation

## Website

Open the HTML files in a browser to explore the interface.

## Limitations

Model performance and scientific conclusions should be assessed
using held-out data and documented evaluation metrics.
